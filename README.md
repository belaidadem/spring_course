## Overview
This project is a Spring Boot application for a Library Management System. It allows for managing books and users with different roles in a library context.

For a comprehensive overview of the project, including detailed documentation, architecture, and implementation details, please visit: [Comprehensive Project Report: Library Management System](https://cuddly-thunder-ce1.notion.site/Comprehensive-Project-Report-Library-Management-System-1e55da6b287a80f6b75be9d6907213e3?pvs=4)
## Tech Stack
- Spring Boot 3.4.4
- Java 21
- Spring Web
- Gradle

## Running the Application
### Prerequisites
- Java 21 (or JDK 17+) installed on your system
- Command line terminal or PowerShell

### Steps to Run
1. Open a terminal or command prompt
2. Navigate to the folder containing the JAR file
3. Execute the following command:
``` 
   java -jar spring_course-1.0-SNAPSHOT.jar
```
1. The application will be available at: [http://localhost:8080](http://localhost:8080)
2. The server runs until you press Ctrl+C to terminate it

## Features
- Book management (add, update, delete, search)
- User management with different roles (Admin, Librarian, Member)
- Borrowing and returning functionality
- Inventory tracking

## Project Structure
- Controllers: Handle HTTP requests
- Services: Contain business logic
- Models: Represent data entities
